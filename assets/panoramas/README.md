# Optional panorama backgrounds

Place a 2:1 equirectangular image here, such as `panorama_4096x2048.jpg`.

In `scenes/Main.tscn`, select `World/Environment` and assign the imported texture
to **Panorama Texture**. An empty field uses the procedural sky. No code or fixed
filename is required. This texture is a static background, not a video export.

No external panorama is included. If you add one for distribution, record its
source, license and any attribution in the root `THIRD_PARTY_NOTICES.md`.
