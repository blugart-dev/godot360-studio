# Publishing the example films on YouTube

Public viewing links and reusable titles/descriptions for **THRESHOLD**, **LUMEN**,
**AFTERGLOW** and **UMBRAL**. The [repository](https://github.com/blugart-dev/godot360-studio)
and [1.0.0 downloads](https://github.com/blugart-dev/godot360-studio/releases/tag/v1.0.0)
are public. These drafts describe the existing films; they do not claim that the
older renders were produced with the released 1.0.0 build.

Verified **2026-09-14**: all four watch pages and the playlist open in a signed-out
browser on **Blugart Games**. Each film exposes YouTube's spherical navigation
control. This verifies public access and 360° recognition; it does not establish
every playback quality, device, frame or subjective listening result. The owner
published the videos and supplied these links; the project sweep did not edit YouTube.

## Checklist for future uploads or edits

1. In **Content**, open each matching film and paste its title and description.
   Preserve any existing creator credits that should remain. Save the details.
2. Preview the upload in YouTube. Confirm drag-to-look, orientation, available
   resolution, the complete duration and music through the ending. Check the
   upload's processing and restrictions status. YouTube recommends checking 360°
   navigation before publication; see its [spherical-video guide](https://support.google.com/youtube/answer/6178631?hl=en).
3. Open the description on the watch page and test the repository/download links.
   Clickable external links require channel access to advanced features; see
   [YouTube's link guidance](https://support.google.com/youtube/answer/13748639?hl=en).
4. For the selected films, choose **Visibility → Public → Save** (or the publish
   button shown for that upload). See [YouTube's visibility instructions](https://support.google.com/youtube/answer/157177?hl=en).
5. Open each watch URL while signed out to confirm public access. Update the public
   film table above and the **Watch in 360° on YouTube** links in the project README,
   matching film guide and showcase. Keep the flat previews available too.

THRESHOLD's four chapter sections are at least ten seconds long. LUMEN is too
short for three such chapters; AFTERGLOW's musical sections include shorter
passages. Their drafts therefore omit chapter markers. YouTube documents the
[chapter requirements](https://support.google.com/youtube/answer/9884579?hl=en).
All descriptions fit its [5,000-character limit](https://support.google.com/youtube/answer/12948449?hl=en).

Playlist title: **Made with Godot360 Studio | 360° Films**. Add the repository as a channel profile link
named **Godot360 Studio · Source & Downloads** if it fits the channel's scope.
